# Модуль подачи заявок (Requisition Module)

Модуль реализует опросы пользователей (FSM-опросники) для сбора заявок на консультации или вступление в закрытое сообщество, а затем отправляет собранные данные на бэкенд.

## Структура файлов

```text
app/modules/requisition_module/
├── states.py       # Группы состояний FSM для каждого продукта
├── keyboards.py    # Inline и Reply клавиатуры (выбор, отмена, отправка контакта)
├── handlers.py     # Обработчики команд и ввода пользователя
├── AGENTS.md       # Инструкции для ИИ-агентов (English)
└── README.md       # Описание модуля (Russian)
```

## Функционал

1. **Команда `/apply`**
   * Выводит меню выбора продукта для подачи заявки: "Заявка на консультацию 📅" или "Заявка в сообщество 👥".
   * Кнопка "Отмена" сбрасывает состояние.

2. **Заявка на консультацию (`consultation`)**
   * Последовательно запрашивает:
     1. Имя пользователя.
     2. Номер телефона (через специальную Reply-кнопку «Поделиться контактом» или текстовый ввод).
     3. Описание цели консультации.
   * При успешном заполнении отправляет данные POST-запросом на бэкенд и выводит сообщение об успешной отправке.

3. **Заявка в сообщество (`community`)**
   * Последовательно запрашивает:
     1. Имя пользователя.
     2. Ссылку на соцсети или краткое описание опыта.
     3. Описание мотивации.
   * При успешном заполнении отправляет данные на бэкенд и выводит сообщение об успешной отправке.
