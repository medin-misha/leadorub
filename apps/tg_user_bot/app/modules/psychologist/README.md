# Модуль воронки психолога (psychologist)

Этот модуль реализует интерактивную воронку продаж для Telegram-бота психолога с интеграцией с Telegram Mini App. Используется в качестве демонстрационного прототипа (превью) продукта для потенциального клиента.

## Функционал

Модуль предоставляет следующие возможности:
1. **Интерактивное меню**: Переключение разделов (/start -> Главное меню).
2. **Описание услуг**: Презентация трех основных видов психологических консультаций (индивидуальная, семейная, экспресс).
3. **Контакты**: Показ контактных данных (канал, номер телефона) с возможностью быстрого возврата в главное меню.
4. **Запись через Mini App**: Кнопка «Записаться» предлагает пользователю открыть встроенное Mini App.

## Telegram Mini App (client_miniapp)

В папке `apps/client_miniapp` находится полноценное Vue 3 SPA приложение, спроектированное в аккуратном спокойном темном стиле:
* **Выбор формата сессии**: Индивидуальная, семейная или экспресс-сессия.
* **Ввод данных**: Имя, телефон и краткое описание запроса/проблемы.
* **Безопасная передача данных**: При отправке формы Mini App передает данные обратно боту через `Telegram.WebApp.sendData`.
* **Обработка данных**: Бот перехватывает событие отправки (`F.web_app_data`), сохраняет заявку в базе данных бэкенда с типом `"consultation"` (через API `X-Service-Token`) и выводит красивое подтверждение в чат с автоматическим удалением временных кнопок.

## Настройка домена и Caddy

В Docker-окружении (`infra/docker-compose.apps.yml`) приложение `client_miniapp` разворачивается на порту `8081` и обслуживается через прокси Caddy.
Caddy автоматически терминирует HTTPS и раздает приложение на поддомене `app.{$PUBLIC_HOST}` (например, `https://app.34-51-187-234.sslip.io`), что гарантирует беспроблемное открытие Mini App внутри Telegram.

## Конфигурация
Для работы бота требуется указать URL приложения в файле окружения `.env`:
```env
CLIENT_MINIAPP_URL="https://app.<your-ip>.sslip.io"
```
